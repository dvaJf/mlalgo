# Anomaly Detection — Sinuc

Интерактивный проект для генерации синтетических временных рядов и демонстрации различных алгоритмов обнаружения аномалий. Включает в себя веб-интерфейс (Streamlit) и скрипты для пакетного тестирования алгоритмов.

## Описание

Проект реализует два независимых подхода к поиску аномалий (выбросов) в числовых последовательностях:

1. **Статистический метод (MAD + Z-score)** (`detect.py`) 
   Использует скользящую медиану (Median Filter) и медианное абсолютное отклонение (MAD). Этот подход идеально огибает сложные формы сигналов (синусоиды, пилы, квадраты) и устойчив к самим аномалиям, что делает его крайне надежным и робастным.
2. **Machine Learning метод** (`detectai.py`)
   Использует алгоритм `Isolation Forest` (изолирующий лес) на основе извлеченных инженерных признаков (остатки сглаживания, локальный разброс). Порог отсечения аномалий выбирается адаптивно по методу "колена" (максимальный скачок в скорах).

Данные генерируются с помощью гибкого класса `SineGenerator` (`gener.py`), который умеет создавать различные базовые сигналы (включая поддержку кастомных математических формул), накладывать гауссов шум и внедрять случайные точечные аномалии.

## Структура репозитория

```text
- test_detect.py     Главное веб-приложение Streamlit (UI)
- gener.py           Генератор синтетических рядов с шумом и аномалиями
- detect.py          Статистический детектор (MAD)
- detectai.py        ML-детектор (Isolation Forest)
- metrics.py         Подсчет метрик классификации (Precision, Recall, F1)
- create_dataset.py  Скрипт генерации большого тестового датасета
- test.py            Пакетное тестирование статистического детектора
- testml.py          Пакетное тестирование ML-детектора
- test_data.csv      Сгенерированный датасет (100 рядов)
```

## Быстрый старт

Установите необходимые зависимости:

```bash
pip install -r requirements.txt
```

### Запуск веб-интерфейса (Streamlit)

Интерактивная панель позволяет настраивать параметры сигнала "на лету", генерировать графики, переключать алгоритмы и загружать собственные CSV-файлы для анализа:

```bash
streamlit run test_detect.py
```

### Массовое тестирование алгоритмов

1. Сгенерируйте датасет (создаст `test_data.csv` на 100 рядов):
   ```bash
   python create_dataset.py
   ```
2. Проверьте качество работы статистического алгоритма (MAD):
   ```bash
   python test.py
   ```
3. Проверьте качество работы алгоритма машинного обучения (Isolation Forest):
   ```bash
   python testml.py
   ```

## Параметры генератора сигналов

При использовании генератора вы можете гибко настраивать данные:

| Параметр       | Описание |
|----------------|----------|
| `signal_type`  | Тип сигнала: синусоида, косинусоида, пила, квадрат или формула |
| `n_points`     | Количество точек во временном ряде |
| `noise`        | Стандартное отклонение (std) гауссова шума |
| `anomaly_count`| Число внедряемых точечных аномалий |
| `anomaly_scale`| Амплитуда скачка аномалии |

## Метрики оценки

В скриптах тестирования используется модуль `metrics.py` для оценки качества по трем основным метрикам:
- **Precision (Точность)** — доля действительно аномальных точек среди всех, что детектор счел аномалиями (насколько мы можем доверять срабатыванию).
- **Recall (Полнота)** — доля найденных аномалий среди всех реальных аномалий в ряде (сколько аномалий мы не пропустили).
- **F1-score** — гармоническое среднее между Precision и Recall.
