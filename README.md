# Anomaly Detection

Репозиторий с проектом для генерации временных рядов и детекции в них точечных аномалий. Изначально проект создавался для синусоидальных данных, но теперь поддерживает генерацию сигналов на основе пользовательских математических формул.

## Описание

Проект содержит два основных подхода к поиску аномалий:
1. **Статистический метод** (`detect.py`) — использует скользящее окно с вычислением Z-score.
2. **Машинное обучение** (`detectai.py`) — применяет алгоритм Isolation Forest на сгенерированных признаках (скользящее среднее, стандартное отклонение) с автоматическим выбором порога отсечения по "колену" (knee method).

Для визуализации и интерактивной работы предусмотрен **веб-интерфейс на базе Streamlit**.

## Структура репозитория

```text
.
├── gener.py           # Генератор синтетических рядов с аномалиями (синусоиды и кастомные формулы)
├── create_dataset.py  # Скрипт для создания датасета из 100 рядов (сохраняется в test_data.csv)
├── detect.py          # Статистический детектор (скользящее окно + Z-score)
├── detectai.py        # ML-детектор (Isolation Forest + knee threshold)
├── test.py            # Оценка статистического детектора в консоли (Precision/Recall/F1)
├── testml.py          # Оценка ML-детектора в консоли (Precision/Recall/F1)
├── test_detect.py     # Интерактивный веб-интерфейс (Streamlit)
├── metrics.py         # Скрипт для вычисления метрик классификации
└── test_data.csv      # Сгенерированный датасет для тестирования
```

## Установка

Для работы проекта необходим Python. Рекомендуется использовать виртуальное окружение. Установите зависимости:

```bash
pip install -r requirements.txt
```

## Использование

### 1. Интерактивный веб-интерфейс (Рекомендуется)

Самый удобный способ визуализации работы алгоритмов — запуск Streamlit-приложения:

```bash
streamlit run test_detect.py
```

В веб-интерфейсе вы можете:
- Генерировать сигналы "на лету" (включая использование пользовательских математических формул, например `x**2+x`).
- Загружать собственные CSV файлы (с колонками `x`, `y` и опционально `is_anomaly`).
- Сравнивать работу статистического и ML-методов детекции на интерактивных графиках.

### 2. Генерация данных (через CLI)

Если вам нужен CSV-файл с выборкой из нескольких рядов:

```bash
python create_dataset.py
```
Скрипт создаст `test_data.csv` со 100 временными рядами по 3000 точек.

### 3. Запуск детекторов в консоли

Оценка качества (Precision, Recall, F1-score) на сгенерированном датасете `test_data.csv`.

**Статистический детектор:**
```bash
python test.py
```

**ML-детектор (Isolation Forest):**
```bash
python testml.py
```

## Параметры генератора (SineGenerator)

При использовании класса `SineGenerator` или через веб-интерфейс доступны следующие настройки:

| Параметр       | Описание                          |
|----------------|-----------------------------------|
| `signal_type`  | Тип сигнала (`sine` или `custom`) |
| `formula`      | Строка с математической формулой (для `custom` типа) |
| `n_points`     | Число точек в генерируемом ряду   |
| `noise`        | Стандартное отклонение гауссова шума |
| `anomaly_count`| Количество аномальных точек для вставки |
| `anomaly_scale`| Амплитуда скачка аномалии (масштабируется относительно сигнала) |
| `amplitude`    | Амплитуда базового сигнала |
| `frequency`    | Частота базового сигнала |
| `start`/`end`  | Диапазон значений по оси X |

## Метрики оценки

Для каждого проанализированного ряда вычисляются:
- **Precision** — доля верно найденных аномалий среди всех точек, отмеченных как аномалии.
- **Recall** — доля найденных аномалий среди реальных аномалий.
- **F1-score** — гармоническое среднее Precision и Recall.
